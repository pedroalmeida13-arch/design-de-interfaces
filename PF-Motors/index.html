Termos de Uso e Aviso de Privacidade

1. Natureza do projeto. PF Motors é um protótipo acadêmico de loja de veículos. Os anúncios, preços, contas e pedidos têm finalidade exclusivamente demonstrativa. Não há venda real por este site.

2. Dados utilizados. O formulário solicita nome, e-mail, telefone e senha para demonstrar cadastro e login. O endereço é solicitado apenas quando a opção de entrega é selecionada. Não informe dados pessoais reais ou senhas utilizadas em outros serviços.

3. Finalidades. Os dados servem para autenticar a conta de demonstração no próprio navegador, preencher a solicitação simulada e registrar suas preferências. A opção de receber ofertas é facultativa e não dispara mensagens.

4. Armazenamento e segurança. Informações básicas da conta e um verificador criptográfico de senha são armazenados localmente neste navegador. Não existe servidor de autenticação ou banco de dados remoto. A limpeza dos dados do navegador remove a conta; o projeto não é adequado a uso comercial sem infraestrutura adicional.

5. Consulta de CEP. Ao digitar um CEP, apenas os oito dígitos informados são enviados ao serviço público ViaCEP para preencher logradouro, bairro, cidade e estado. Consulte também a política do serviço externo.

6. Direitos e consentimento. O aceite dos termos é necessário para o cadastro demonstrativo. A preferência por novidades é opcional. Você pode excluir os dados de sua conta local pelo botão “Excluir minha conta” dentro da área de conta.

7. Limites. Este aviso descreve apenas o funcionamento deste protótipo; não representa, por si só, conformidade integral com a LGPD para uma operação comercial.
